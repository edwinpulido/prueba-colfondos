# Catalogo de microservicios Java

Area responsable: Backend Canales Digitales  
Fecha del documento: 2026-01-22  
Estado: Referencia tecnica

## Customer Data Service
Servicio responsable de consultar y actualizar informacion del afiliado a traves de interfaces gobernadas.

## Identity Orchestration Service
Servicio utilizado en flujos de autenticacion, validacion de identidad y manejo de tokens.

## Messaging Service
Servicio responsable del envio de comunicaciones transaccionales.

## Verification Service
Servicio asociado a generacion y validacion de codigos de verificacion.

## Lineamientos tecnicos
- Logging estructurado.
- Correlation ID.
- Manejo centralizado de errores.
- Pruebas unitarias.
- Documentacion de endpoints.
- Variables de ambiente documentadas.
