# Integracion Empresarial - Estado actual

Area responsable: Integracion Empresarial  
Fecha del documento: 2025-12-02  
Estado: Catalogo operativo

## Plataforma
Varias integraciones core se encuentran implementadas en IntegrationHub OnPrem.

## Capacidades documentadas
- Consulta de informacion de afiliado.
- Actualizacion de datos basicos.
- Envio de notificaciones.
- Validaciones de identidad para algunos procesos digitales.

## Observaciones operativas
- Algunos flujos tienen dependencias sincrónicas con sistemas internos.
- Existen limites de tiempo de respuesta para servicios expuestos al portal.
- Las actualizaciones de datos deben realizarse mediante interfaces gobernadas.
